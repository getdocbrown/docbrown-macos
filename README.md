# Doc Brown

**Pick up where you left off.**

Doc Brown is a macOS app for exploring the history behind your work with AI. It brings prompts, conversations, and their outcomes into one searchable place, so you can find the context you need and carry on.

A project rarely fits inside one chat. You might explore an idea in Claude, build it in Codex, and return days later to remember why you made a decision. Doc Brown is being built to keep that story together.

## Planned features

- **Capture conversations** from Codex and Claude, including your prompts, model responses, and session metadata.
- **Keep history locally** on your Mac, with a searchable archive of your work.
- **Follow workstreams** across sessions and tools instead of treating every chat as an island.
- **Connect conversations to outcomes**, including files, commits, and pull requests when relevant.
- **Find your way back** by searching for a phrase, a topic, a project, or a pull request.

Code is one part of the picture. Research, writing, planning, and all the other conversations that move a project forward belong here too.

## Status

Early development. This repository currently contains the project overview; there is no runnable app or release yet. The features above describe the intended direction.
